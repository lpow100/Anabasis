# Anabasis

Anabasis is a Terraria mod for tModLoader about ascending beyond the stars and facing new cosmic threats. The mod focuses on post-Moon Lord progression while also adding content throughout the earlier stages of the game.

## Current features

- The Blitz damage class, built around mobility, dashing, and momentum.
- Blitz daggers and gauntlets, including early-game weapons.
- The Giant Eel segmented boss and custom boss bar.
- New materials, equipment, tools, accessories, tiles, buffs, and projectiles.
- Planned bosses, progression, and the Basalt Crags biome.

Anabasis is an active work in progress. Some content is implemented, while other features remain documented plans.
