[Anabasis]

Anabasis is a content mod for Terraria that adds new content throughout the game on a similar sense to Thorium and Macrocosm. The mod is centered around adding content to bring the avatars of the solar system to life with mostly Post-ML content.

Anabasis is an active work in progress. Some content is implemented, while other features remain documented plans.

[[Documentation]]

Design notes and the current development checklist are available in [`Docs/Anabasis`](https://github.com/lpow100/Anabasis/Docs/Anabasis). The class and progression documents describe the intended direction of the mod.

[[Development]]

This repository is developed collaboratively. Contributions, testing, balancing feedback, art, and design work are welcome when coordinated with the project maintainers.

This repository is kept open source to allow collaboration and allow other people to learn from the code.
